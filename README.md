# betterHotKey

> [NOTE] 若有反馈，请发送反馈到bugsoc@qq.com / If you have any feedback, please send it to bugsoc@qq.com

> 让建造快捷键变成习惯，而不是需要反复寻找的菜单。

betterHotKey 改善 Mindustry 的建造键位体验。它帮助你保持稳定的数字建造顺序，为常用建筑安排组合键，并在建筑信息中直接看到对应提示。

它适合经常用键盘速建、希望避开地形干扰，或想把传送带、工厂和电力建筑绑定到固定手感的玩家。进入 设置 → Mods → betterHotKey 即可按自己的工作流调整。

## 使用

启用模组后打开设置，先决定是否忽略地形干扰，再进入自定义快捷键配置。完成绑定后，建筑信息栏会显示快捷键提示。

## English

> Make building shortcuts part of your muscle memory instead of another menu to search.

betterHotKey improves the building-key workflow in Mindustry. It helps keep numeric building order stable, gives frequently used blocks custom combo keys, and shows the assigned shortcut directly in building information.

It is for players who build with the keyboard, want to avoid terrain interference, or prefer fixed shortcuts for conveyors, factories, and power blocks. Configure it under Settings → Mods → betterHotKey.

## Usage

Enable the options you need, open the custom shortcut editor, and bind the blocks you use most. The assigned shortcut will be shown in the building information panel.
