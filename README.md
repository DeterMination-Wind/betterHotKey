一个让 Mindustry 建造快捷键更稳定、更顺手的客户端模组。

## 本次更新（v1.1.0）
- 新增建筑图标右下角快捷键角标显示与角标字号调节。
- 角标编号现在会正确适配“忽略地形”选项。
- 修复角标字号输入：输入 `0.5` 这类小数时，不会因为先输入 `0` 而中途报错。
- 补充 `bekBundled / bekBuildSettings` 接口，方便并入 Neon 聚合设置。

## 功能简介
- 建筑图标右下角会直接显示对应的快捷键角标，查看时更直观，还能单独调节角标字号。
- 数字快捷键可以忽略地形、装饰和其他干扰方块，让常用建筑的编号更稳定。
- 被禁用的建筑会保留在原来的菜单位置，避免后面的快捷键顺序被打乱。
- 支持自定义组合快捷键，例如把常用建筑绑定成 `A + A`、`Q + E` 或 `A + B + C`。
- 支持按分组整理自己的快捷键配置，方便长期游玩时维护。

## 使用方法
1. 进入游戏后，打开 `设置 -> Mods -> betterHotKey`。
2. 按需要开启以下选项：
   - `启用 betterHotKey`
   - `数字快捷键忽略地形`
   - `启用自定义组合快捷键`
3. 点击 `打开自定义快捷键配置`，给常用建筑设置二键或三键组合。
4. 回到游戏后，把鼠标移到建筑上，就能在原版建筑信息栏里看到快捷键提示。
5. 之后直接按数字键，或按你设置的组合快捷键，就可以快速切换到目标建筑。

## 适合谁
- 想让数字键建造顺序保持稳定的玩家。
- 经常用键盘快速建造的玩家。
- 想给传送带、工厂、电力建筑等常用内容单独设快捷键的玩家。
